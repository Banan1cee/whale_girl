# 手机远程控制

## 使用教程

1. 安装鲸鲸时保留「安装手机远程控制」。打开鲸鲸，再打开同目录的「手机远程控制」文件夹。
2. 电脑双击「1 - 下载或安装 Tailscale」。手机按系统下载 Tailscale，然后两台设备登录同一个专用网络。[iPhone / iPad App Store](https://apps.apple.com/us/app/tailscale/id1470499037?ls=1) · [安卓官方下载](https://tailscale.com/download/android) · [安卓官方 APK](https://dl.tailscale.com/stable/#android)
3. 双击「2 - 一键打开控制台」，记下配对 Key，保持命令窗口开启。
4. 双击「3 - 一键复制手机访问地址」。按提示完成 Windows 权限确认和首次 HTTPS 授权，看到「地址已复制」后把网址发给自己的手机。
5. 手机用浏览器打开网址，首次输入配对 Key。以后用同一浏览器打开同一个网址。

电脑保持通电和联网，桌面鲸鲸和第 2 步窗口保持开启。手机控制台通过 Tailscale Serve 提供 HTTPS 访问。[Tailscale Serve 文档](https://tailscale.com/docs/features/tailscale-serve)

## 功能介绍

- 手机可以停止内核、看诊断，并调整人设、模型、群聊和桥接设置。桌面启动器以管理员权限运行时，请在电脑上启动内核或重启程序。
- 状态页的「主机」卡片可以查看电脑是否锁屏、当前输入桌面和空闲时长，切换保活（防睡眠 / 防关屏）、点亮屏幕、允许手机启动内核和设置开机自启。锁屏时朋友圈、表情包、引用回复等依赖截图的功能会失效，卡片会提示先用 UU/ToDesk 等远控解锁再操作。
- 手机可一键点亮屏幕 / 关闭屏幕（关屏不锁屏）、切换保活模式、允许手机启动/重启内核、设置开机自启；主机状态每 20 秒自动刷新。
- 表情包、语音发送和朋友圈发表使用桌面端的总开关。朋友圈的自动读取、自动点赞和定时发表各有独立设置。
- 配对 Key 允许启停应用和更改设置，只输入到你自己的设备。首次授权完整系统权限的 JavaScript 插件、设置微信数据库路径，请在电脑上操作。改模型接口站点时填写对应 API Key。
- 关闭第 2 步窗口可以停止控制台，停用转发时按 Tailscale 文档关闭对应 Serve 端口。要换配对 Key，关闭窗口后删除当前 Windows 用户 `%LOCALAPPDATA%\WhaleGirlRemoteConsole\saved-pairing-8790.xml`，再打开第 2 步。自定义端口用户使用对应端口号的文件。[停用 Serve](https://tailscale.com/docs/reference/examples/serve)

## 测试

在源代码根目录运行 `node tests/phone-remote-console.test.js`。测试使用本机模拟服务，覆盖配对、开关、离线设置和表情包预览。

## 排障：手机浏览器打不开控制台地址

浏览器提示「无法访问此页面 / DNS_PROBE_FINISHED_NXDOMAIN」时，**不是电脑关机**，是手机的 DNS 没走 Tailscale。按顺序检查：

1. 手机 Tailscale 已登录**同一个账号**，并且开关是 Connected；电脑端 `tailscale status` 里手机不应显示 offline。
2. 手机 Tailscale 设置里打开「Use Tailscale DNS / 使用 Tailscale DNS」。
3. 安卓「设置 → 网络和互联网 → 私人 DNS」选「关闭」或「自动」；浏览器的「安全 DNS / DoH」（小米浏览器、Chrome 的「使用安全 DNS」）会绕过 MagicDNS，需要关掉。
4. 安卓会为省电杀掉 Tailscale 后台：设置 → 应用 → Tailscale → 电池 → 无限制；Tailscale 里可再开 Always-on VPN。
5. 控制台只能通过 `https://<主机名>.ts.net` 访问；用 tailnet IP 会因证书域名不匹配而 TLS 失败，不要用 IP。
6. 想确认控制台本身有没有问题，先在电脑浏览器打开 `http://127.0.0.1:8790` 输入配对 Key，能进就是手机侧网络问题。

上面的链路都正常还打不开时，在电脑上跑 `tailscale serve status` 确认 Serve 还在，必要时重新执行「2 - 一键打开控制台」和「3 - 一键复制手机访问地址」。

## 兼容性：关闭屏幕 / 点亮屏幕

- 不依赖显示器品牌，也不发 DDC/CI 或任何厂商私有指令；用的是 Windows 标准的 DPMS 广播和合成输入唤醒。
- **手机端「打开/关闭屏幕」默认关闭，且仅台式机可用**：需先勾选「允许远程开关屏幕」才出现这两个按钮；桌面端只保留「关闭屏幕」（人在电脑前不需要远程亮屏）；笔记本上不显示（关屏多数机型等同进入现代待机，唤醒要重新登录，看起来就是锁屏）。
- 台式机也要求电源设置「控制台锁定显示关闭超时」为 0，否则关屏会主动锁屏，这种情况同样禁用并提示。
- 点亮屏幕、保活、手机启内核在台式机和笔记本上都可用。
- 笔记本合盖或进入睡眠后整台电脑离线，手机连不上，这要靠 WOL / 自动登录解决，不是显示器问题。
- 多显示器会一起关、一起亮；只想黑一块屏需要 DDC/CI，本版不做。
- 个别显示器深度节能时，点亮后可能要等 1~2 秒才有画面；若长时间不亮，请检查显示器电源开关和「节能/自动关机」设置。
