# 对话风格学习

从**已经发生过的聊天**里总结使用者的说话习惯，生成一份只存在于本机的风格画像，再让回复参考它。默认有两个模式：

| 模式 | 配置值 | 行为 |
| --- | --- | --- |
| 贴合对方习惯 | `adapt` | 学对方的句长、语气、标点、常用语气词和常聊话题，让回复更合拍；不冒充对方本人。 |
| 模仿对方表达 | `mimic` | 在上述基础上更接近对方的句式、节奏和口头禅；仍然不冒充身份，也不复制错别字、隐私或攻击性表达。 |

## 数据从哪里来

### 1. 已有记忆（默认）

分析 `data/memory/chats/<hash>/messages.jsonl` 里已经保存的聊天。适合已经运行过一段时间、积累过对话的部署。

- 主人识别优先用 `persona.master.wxids`，其次 `persona.master.names`。
- 没有配置主人名单时，只从**私聊**里取对方的消息来推断，结果会标记为「推断主人」。
- 群聊里无法确认谁是谁时，不会把群友的消息混进「使用者风格」。

### 2. 微信本地历史导出

新装、记忆还很少时，可以先把微信本地历史导出成 JSON，再分析：

```powershell
# 需要微信已登录、脚本与微信同一用户权限；不会修改 vendor/ 或微信数据库
python scripts/export-wechat-history.py --out data/wechat-history.json --limit 2000
node scripts/learn-style.js --source export --file data/wechat-history.json
```

也可以不带参数直接分析已有记忆：

```powershell
node scripts/learn-style.js
node scripts/learn-style.js --owner wxid_xxx --use-llm
```

输出默认写到 `data/style-profile.json`。启动器「人设 → 对话风格学习」里也能直接点「从已有记忆学习」或选择导出文件。

## 画像里有什么

只保存统计和中文摘要，**不保存原始消息正文**：

- 平均/中位/90 分位句长、短句占比
- 问句、感叹号、省略号、emoji 比例
- 常用语气词、句尾习惯、2~4 字高频短语
- 3~6 条可执行的风格建议（`summary.adapt` / `summary.mimic`）
- 样本数、会话数、生成时间、是否推断主人

`data/style-profile.json` 可以被删除或重新生成；它不是聊天记录，也不参与记忆备份。

## 可选：让模型总结

启动器卡片里的「让模型总结抽样消息」默认不勾。勾选后：

- 发给当前模型的只有统计和最多 30 条、每条截断 120 字的抽样；
- 不发送姓名、wxid 或完整聊天记录；
- 模型失败或返回格式不对时，保留本地统计生成的确定性摘要。

## 开关与接口

| 位置 | 作用 |
| --- | --- |
| `features.styleProfile` | 总开关，默认开；关闭后即使有画像也不注入提示词 |
| `persona.styleMode` | `adapt` / `mimic`，默认 `adapt` |
| `persona.styleScope` | `owner`（默认，只在主要联系人说话时参考）/ `all`（群聊/其他人也参考）；群聊另有「学这个群说话」 |
| `data/style-profile.json` | 画像文件；不存在时完全不产生提示词 |
| `GET /api/persona/style` | 读取当前模式和画像（启动器使用） |
| `POST /api/persona/style/analyze` | `{source:"memory"\|"export", file?, owner?, useLlm?}`；只允许本机 |
| `POST /api/persona/style/mode` | `{mode:"adapt"\|"mimic"}` |
| `POST /api/persona/style/clear` | 删除画像，恢复为不使用风格参考 |

## 边界

- 这是**风格参考**，不是身份替换：提示词明确要求不冒充对方、不复制隐私或攻击性表达。
- 群聊里已有的「学这个群说话」仍按最近消息实时估计，不受这份画像影响。
- 画像只描述使用者，不描述群友；如果主人名单没配置，群聊样本会被跳过。
- 画像不会改变模型、人设、记忆或安全规则；它只追加一段静态提示词。
- 微信历史导出依赖 `vendor/wechatauto` 和本机数据库权限，失败时按脚本提示检查微信是否登录、路径是否正确。
